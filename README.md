# 方寸输入法 · FangCun

macOS 原生输入法：离线中文拼音 + 用户主动触发的 AI 文字处理，支持翻译、润色和问答。使用 Swift、AppKit、InputMethodKit 与 Rime；没有网页主界面。

## 本机构建和安装

需要 macOS 13+、Xcode Command Line Tools 和 Python 3。

```sh
./scripts/bootstrap.sh
./scripts/build.sh
./scripts/test.sh
./scripts/install.sh
```

安装到 `~/Library/Input Methods/FangCun.app`。安装程序注册并尝试启用输入源；若菜单中暂未显示，请在「系统设置 → 键盘 → 文本输入 → 编辑 → ＋ → 简体中文」中添加「方寸输入法」。首次安装可能需要重新登录。升级时安装器会启动新版并等待输入服务就绪；升级后请在原应用窗口确认能继续输入。

本机构建安装脚本与 DMG 共用安装服务：正常退出本产品进程，沿用原路径原子替换及回滚，备份保存在 `~/Library/Application Support/FangCun/Installer/Backups/`。已有 `.build/*-previous-*.snapshot` 不会删除。`FANGCUN_OPEN_SETTINGS=0` 仍可抑制首次安装自动打开设置。安装时会注销本次工程构建副本在 Launch Services 中的登记，避免系统启动错误路径。

升级时已打开的应用能否恢复原输入会话仍需实机验证。实现、检查结果和试验步骤见 [原子升级验证记录](docs/testing/atomic-upgrade-build46.md)。

## 使用

- 默认中文模式：全拼打字，空格或数字选词，中文直接上屏。支持连续整句全拼、`nv/lv` 和隔音符号。
- **表情和符号候选**：输入中文名称的拼音即可选 emoji，例如 `zan` →「赞、👍」、`zhengfangxing` →「正方形、⬛、⬜、🟥…」、`wujiaoxing` →「五角星、⭐、🌟、★、☆」、`xiaolian` →「笑脸、😄、😊、🙂」。内置 144 个名称，支持点赞、爱心、哭脸、圆形、三角形等；中文词保留在前，表情可用数字、方向键加空格或点击选择，多个颜色可翻页。全拼、七种双拼及临时编辑区共用，离线可用。
- **双拼**：设置 → 输入 → 拼音输入方式选「双拼」，再选方案。支持搜狗、小鹤、自然码、微软、智能 ABC、拼音加加、紫光；也可从系统输入法菜单的「拼音方案」切换。自动保存，不需要填写模型配置。若有未选完的拼音，会在这段选完后切换，已确认的译英草稿保留。详细键位样例和验收见 [双拼使用与验收](docs/testing/double-pinyin-build13.md)。
- 拼音中可以直接夹英文：`tuopanlidelogo` → `托盘里的logo`，`woyaoxiugaibug` → `我要修改bug`。中英重码时提供候选，例如 `women` 优先显示「我们」，也可选择英文。
- **Shift** 单独轻按切换中英文直输；长按、配合字母、快捷键或鼠标操作不会切换。切换到其他输入法再返回方寸时默认中文，保留所选拼音方案。系统只保留一个「方寸输入法」入口，中英切换不改变输入源。附加的紫色语言状态图标随模式显示「中」或「英」，切换到其他输入法时隐藏；系统原生输入菜单图标仍固定为「方」。候选窗显示当前方案简称或「EN」，点击也可切换中英文。英文直输保留半角标点。
- 有未选词的拼音时 **Enter** 原样输入字母，不将 `logo` 改为中文或添加显示用的分隔空格。已有待定句号时，Enter 确认预编辑区显示的内容。
- **中文标点**：未确认拼音后按逗号、问号等中文标点，会同时确认当前高亮候选，例如 `nihao → ,` 得到 `你好，`，无需先按空格。未选拼音后的 `.` 先显示为中文句号，继续输入或按确认键时再提交。选完词后的句号立即提交。`/` 和 `\` 输入顿号 `、`，双引号依次输入 `“` 和 `”`。
- 中文模式可直接输入 `baidu.com`、`www.baidu.com` 等网址，裸域名识别 `.com`、`.cn`、`.net` 和 `.org`。`@`、`_`、`|` 等普通符号也可开启原文片段，例如 `test@example.com`、`foo_bar`。片段内后续字母、数字和符号保持原样，空格、Enter 或点击「原文」确认整个片段。输入带协议的完整网址、路径和代码时，可轻按 **Shift** 切到英文模式，所有标点保留半角。
- 拼音状态保留 **`-` / `=` / `+` 翻页**和 **`'` 隔音**；搜狗、微软、紫光双拼保留 **`;` 编码**。这些键进入「原文」片段后按普通字符输入。片段首个符号属于这类功能键时，可先轻按 Shift 切英文输入。
- 点击候选窗的 AI 动作名称，或按 **Ctrl + Shift + E** 开启：选词后暂存在预编辑区，英文直输也会暂存。默认动作是「译英」，旁边的下拉箭头可选择英语润色、回答问题等预设或已有自定义动作；选择动作不会改变开关状态。
- **设置 → 候选动作**：选择动作、编辑指令或新建自定义动作。动作名称就是候选框按钮的名称，过长时缩略显示；指令独立使用，不附加翻译规则。与临时编辑区共用动作库，两处分别记住所选动作。保存立即生效，不调用模型。
- **Ctrl + Enter** /「执行」：选词全部完成后，主动处理整段草稿一次。只要还有未确认的输入，快捷键不执行 AI，按钮显示「先完成选词」或「先确认原文」并禁用；拼音、候选和光标位置全部保留。
- 处理完成后 **Enter** / 空格：只将结果上屏，原文不会一起插入。数字 **2** 可选择原文。英语润色时先轻按 Shift 切到 EN，再输入英语；回答问题时输入问题，完成选词后执行，Enter 只将答案上屏。
- **Esc**：从结果返回原文修改；再次按 Esc 清空预编辑区。切换、编辑或删除候选动作会取消旧请求并清除旧结果，保留当前输入；删除所选自定义动作后回退到译英。
- AI 动作开启且没有未选词拼音、尚未有结果时，**Enter** 可直接原文上屏。需要多段换行时，使用临时编辑区。
- **Ctrl + Shift + Enter**：打开原生临时编辑区，也可点击候选窗的放大按钮或系统输入法菜单「临时编辑区…」。在「设置 → 输入」中点击快捷键可修改。快捷键在方寸输入法处于当前输入源时生效。
- **临时编辑区**：支持全拼、七种双拼、英文混输、选区替换、粘贴、撤销和长文滚动；空格继续选词，选词完成后 Enter 换行，Ctrl + Enter 主动执行动作。未选完的拼音会随放大保留，仍需完成选词才能翻译或上屏。译文可直接修改，通过「原文上屏」或「英文上屏」一次写回原输入框。
- 编辑区默认「改文字 → 翻译成英语」，支持德语、提取约定、自然改写和自定义动作；第二页「问 AI」是支持多轮对话、流式输出和自主工具调用的通用 agent。动作可以设置名称、`/key` 和特殊指令；详见 [原生 AI 动作使用与验收](docs/testing/ai-actions-build22.md)。
- 编辑区内 **Cmd + Enter 快捷上屏**：提交修改后的结果，有选区时仅提交选中部分。改文字模式在尚未生成结果时可直接提交原文；旧结果失效时不会误提交。**Cmd + Shift + Enter** 在改文字模式明确上屏原文。问 AI 不会把问题自动插回输入框。未完成选词时不提交；请求期间等待结果。
- 编辑区内 **Esc** 优先取消当前未确认拼音；无待选输入时保留并收起。关闭窗口或 **Cmd + W** 只收起草稿，再次用快捷键继续；上屏后可点「上次内容」再次取用回答；草稿暂存在本次输入法进程内。原应用、输入框或光标发生变化时先保留草稿，需要返回原输入框或确认新光标，再上屏。
- 拼音末尾按右键选择下一个候选，按左键回到上一个候选，可连续跨页。回到全局第一项后再按左键，才进入拼音编辑；此时左右键逐字移动光标，移回末尾后再按右键继续选词。空格确认当前高亮项；上下键仍可选择候选。
- 有拼音候选时，**`-` 上一页，`=` 或 `+` 下一页**，也支持 Page Up / Page Down 和数字键盘加减号；首末页停住，不循环、不确认文字。无候选、已选完的译英草稿或英文直输时，这些符号正常输入。全拼、双拼均支持。
- 长候选完整显示并自动换行。超长拼音、中文草稿和译文可在窗口内滚动查看；拼音光标和高亮候选自动保持可见。
- 从候选窗齿轮或系统输入源菜单打开「设置」。输入方案在「输入」页，模型、API Key、英语翻译偏好在「AI」页，候选框动作在「候选动作」页。也可运行 `open -a FangCun fangcun://settings`。

系统输入菜单中只有一个可选的「方寸输入法」入口，原生图标固定为「方」。Shift 在内部切换中英文，另有一个随语言显示「中／英」的紫色状态图标，仅在选中方寸时出现；点击可选择「问问 AI…」直接进入问 AI 窗口，也可查看状态、打开设置或继续临时编辑。升级时自动停用旧的「方寸输入法 · 英文」入口。可从系统输入法菜单或候选窗齿轮打开设置，也可运行 `open -a FangCun fangcun://settings`。设置窗口打开时，方寸输入法会出现在 Dock 和 Cmd + Tab 应用切换器；关闭设置窗口后回到菜单栏运行。再次从设置入口打开会保留尚未保存的输入内容。切换输入法、切换应用或后台服务重新打开不会自动弹出设置；首次安装完成时，安装器通过显式设置链接打开设置页。设置顶部展示系统实际可选的输入源状态。

打字、选词、输入标点或停顿均不调用模型。请求期间阻止重复触发；修改原文、切换动作、切换输入源或离开文本会话会取消请求，过期响应无法上屏。失败保留原文，不自动重试。当前会话中相同文字、动作及模型配置可复用最近结果。

## 模型配置

支持 OpenAI-compatible Chat Completions 接口（`POST /chat/completions`，非流式文本返回）。填写基础地址和服务中的模型 ID，例如本地 Ollama 的 `http://localhost:11434/v1`。远程服务使用 HTTPS，本机地址可用 HTTP。

DeepSeek 官方接口明确发送 `thinking: {type: "disabled"}` 关闭思考模式，通用兼容服务不附带这个专属参数。连接可复用，减少重复建立连接的等待；测试翻译显示实际耗时。

API Key 按服务地址分别保存在当前用户的本机私有文件 `~/Library/Application Support/TranslateType/Credentials/api-keys.json`，不再请求钥匙串授权。文件未额外加密，目录权限为 0700、文件权限为 0600；普通配置存入应用偏好。密钥读写全部在后台执行，不占用输入法主线程。代码已完全移除钥匙串访问、迁移和回退逻辑，只读取这个本机文件；没有保存的 Key 需要在设置 → AI 中填写。切换服务地址会清空设置窗中的旧密钥，避免误将旧服务的凭据发送到新地址。请求禁止重定向。

「特殊指令」为空或仅空白时使用默认翻译规则：保留原意、人名及术语，只返回一条自然英文，不带解释。提供自然口语、商务礼貌、简洁直译预设，选择后可以继续修改。特殊指令附加在默认翻译规则后，随下一次整句请求发送；修改指令本身不调用模型。

「测试翻译（调用 1 次）」会真实请求所填服务，用一条示例验证连通性；保存和选择预设不会产生请求。当前没有内置付费密钥或内置大模型，真实翻译需要用户配置可用的服务。

## 验证

`FANGCUN_EDITOR_TEST=AppLifecycleTests ./scripts/editor-test.sh` 验证后台启动、普通重新打开、输入客户端切换和输入源通知不会自动打开设置；同时检查菜单、显式设置链接与 `--settings` 仍可主动打开设置。安装器使用显式设置链接，兼容输入法服务已在后台运行的情况。

build 47 按照确认的 HTML 设计重新实现临时编辑器与问问 AI 的原生界面：统一淡紫色与浅色 / 深色外观，编辑器增加行号和语法着色，问问 AI 增加本次使用的会话侧栏及可折叠工具记录。切换会话保留各自的消息、工作目录、草稿和参考文字，中文选词与原应用插入继续使用现有实现。验证结果及本机 InputMethodKit 模拟客户端限制见 [原生工作窗口验收](docs/testing/native-workspace-build47.md)。

build 42 在紫色「中／英」状态图标菜单的「问问 AI…」下方新增「临时编辑器…」，打开独立的纯文本编辑窗口，与问 AI 的消息和编辑区草稿互不影响。支持中文/英文输入、撤销重做、查找替换、打开 UTF-8 文本、复制及另存文件；`⌘F` 查找，`⌘O` 打开，`⌘S` 另存，`⇧⌘P` 展开/收起右侧预览。关闭窗口保留内容，恢复稿自动存储在本机 `~/Library/Application Support/FangCun/Scratchpad/draft.json`，不会自动覆盖打开的原文件。

预览自动识别 Markdown、HTML、JSON 和纯文本，也可手动选择格式。Markdown 使用本地打包的 Marked 18.1.1，支持标题、表格、列表、任务列表、引用和代码围栏；HTML 展示静态页面与内联样式。预览不运行内容脚本、不自动读取本机资源或加载远程资源，链接由主动点击后在浏览器打开。单份文本上限 2 MB，超过 200,000 字只截取预览，编辑和保存保留全文。`FANGCUN_EDITOR_TEST=ScratchpadTests ./scripts/editor-test.sh` 验证实际 WebKit 渲染、中文输入、撤销重做、文件导入导出及本机恢复稿。

build 41 将「问问 AI」升级为原生消息流 agent，沿用设置中的 OpenAI Chat Completions 兼容模型接口（需支持 `stream` 和 `tools`）。自动完成“模型请求工具 → 执行 → 回传 → 继续回答”的循环，同轮多个工具按序执行，后续消息保留完整工具历史。提供 `read_file`、`write_file`、`edit_file`、`glob_search`、`grep_search`、`shell_exec`、`shell_io`、`shell_manage`、`WebFetch`、`WebSearch`，参考 LoongMate 通才的核心文件、命令和网页工具。平台专属的子 agent、任务编排、插件、Notebook/REPL 不在此版本中；可通过 shell 使用本机已安装程序。

问 AI 页面使用同一个输入框连续发送消息，`⌃Enter` 发送，生成时可编辑下一条草稿。点击「工作目录」选择目录（默认用户主目录）；相对路径从该目录开始，也支持绝对路径，拥有本应用的用户级文件和执行权限。Shell 使用 zsh，无 PTY；长命令返回会话 ID，agent 可读取状态及写入 stdin。停止、切换模式或新建对话会终止当前会话的命令组；文件已产生的修改不会自动回滚。工具日志可选择复制，只有完成的 AI 回答能通过「插入回答」或 `⌘Enter` 上屏。界面支持新建对话、错误后的继续，以及「上次内容」恢复消息和目录。

网页搜索使用 DuckDuckGo HTML，无需额外密钥，网络或验证码限制会作为工具错误回传，不能保证每次搜索成功。网页读取不执行 JavaScript，仅支持 UTF-8 文本。单次消息/参考文字各限 20,000 字，文本文件工具上限 1 MB，Shell 输出保留末尾 64 KB；每次发送最多 16 轮模型调用、48 次工具执行，达到上限后可手动继续。程序不会将模型 API Key 注入工具参数或记录模型请求日志，模型接口重定向被拒绝。`FANGCUN_EDITOR_TEST=AgentTests ./scripts/editor-test.sh` 使用本机 mock 服务和临时目录验证流式协议、多工具循环、真实文件/命令、停止和原生消息界面。

更名保留系统已启用的稳定标识 `com.translatetype.inputmethod.TranslateType` 及其 `.Hans` 模式，只更新展示名称；内部标识不显示为产品名。升级备份原安装，在启用验证成功后清理误创建的第二套安装，验证失败时恢复原安装。

## 依赖与许可

Rime 1.17.0 从官方 release 下载，校验 SHA-256；其许可证随应用资源保留。简体拼音词库来自 rime/rime-pinyin-simp，固定 Git blob `6f2e996d2792416cb7f41bb49967a1dec7060c92`，保留原文件声明。候选窗使用 macOS 系统图标。中文基础词库及英文词汇来自 iDvel/rime-ice，固定中文 Git blob `f1e253ea14ad035198f66b449c83217131184775` 与英文 Git blob `54b596853133044a02216f7131f628c55797b604`。英文编码归一化为小写以用于全拼混输；原始说明和 GPL-3.0 许可证随资源保留。`scripts/prepare-vocabulary.py` 可重建并校验词库。
