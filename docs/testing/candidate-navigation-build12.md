# build 12 候选导航验收

2026 年 10 月 10 日；macOS 14.7.4 / Intel；Rime 1.17.0。

本次按用户明确的操作习惯修正左右键。build 11 把左右键一直用于编辑拼音，与横排候选的预期不符。

## 操作规则

| 当前状态 | 按右键 | 按左键 | 按空格 |
| --- | --- | --- | --- |
| 拼音末尾，第一候选高亮 | 高亮第二候选 | 进入拼音，左移一个字母 | 确认第一候选 |
| 拼音末尾，其他候选高亮 | 高亮下一项 | 高亮上一项 | 确认当前高亮项 |
| 一页的最后一项 | 有下一项时跨页继续 | 高亮上一项 | 确认当前项 |
| 第二页及以后首项 | 高亮下一项 | 回到上一页末项，不能直接进入拼音 | 确认当前项 |
| 全部候选的最后一项 | 停住，不循环 | 高亮上一项 | 确认末项 |
| 光标已在拼音内 | 右移一个字母；到末尾后，下一次右键才选候选 | 左移一个字母；开头停住 | 确认当前转换范围的高亮候选，保留未选尾部 |

例：输入 `nihao`，从第一项依次按 **右、右、左、左、左**，高亮顺序是 **第二项、第三项、第二项、第一项**，最后一个左键才开始编辑拼音。高亮某个候选还不算完成选词。

上下键继续用于移动候选高亮，首末项停住；Page Up / Page Down 保留翻页行为。普通中文模式选完后上屏，译英模式选完后进入待译草稿。尚有未确认拼音时，Ctrl＋Enter 仍被拦截，不代选、不读密钥、不调用模型。

## 验证范围

使用临时 Rime 用户目录和合成测试文字，不使用个人词库。测试会真实学习刚选过的词，因此确认结果应与**当时高亮的候选**比较；不能假设每轮词序永远相同。

| 检查 | 覆盖 |
| --- | --- |
| 连续右移、逐项左退 | 两种模式；高亮变化时原始拼音、草稿和输出不变 |
| 第五项到下一页，以及从下一页左退 | 全局候选索引连续；没有跳项或提前进入拼音 |
| 全局首项左退进入编辑 | 拼音逐字左移，到开头停止 |
| 从拼音开头移回末尾 | 先编辑光标；到末尾后再次右移才选下一项 |
| 第三项加空格 | 确认高亮项，不能强制使用首项 |
| 候选末尾连续右移、再左退 | 到末尾停住，随后仍能向左选择 |
| 上下键边界与拼音编辑中选词 | 保留原操作；不能误传给宿主移动光标 |
| 短候选部分确认后继续选词 | 保留未选尾部，最终结果与前后两次选择一致 |
| `nihaoo` 中间纠错 | 删除移动后光标前的字母，回末尾后正常选词 |
| `ü` 与中文草稿前缀 | 输入框使用正确的 UTF-16 光标位置 |
| 未选完时尝试翻译 | 含只改变高亮、部分选词、拼音中编辑；内容不变，零请求 |
| 实际 IMK 控制器和 NSTextView | 两种模式下右移跨页、左移回选、空格确认与输入框内容一致 |
| 候选窗渲染 | 连续按两次右键后，第三项高亮，“先完成选词”禁用 |

运行入口：`scripts/test.sh`、`scripts/controller-test.sh --capture-navigation .build/build12-candidate-navigation.png`。

执行结果：两个测试入口均成功退出。引擎及组句回归有 282 次通过断言（含逐项导航循环，不代表 282 个独立场景）；控制器报告 14 个通过检查，并包含真实文本光标、选区和上屏状态断言。构建和安装成功；已安装 build 12 的程序与方案文件和构建产物一致，签名校验通过，部署后的方案为 0.4.2。系统注册记录仍是原有方寸输入源，已启用、可选；仅一个已安装方寸进程。

更新时系统当前使用搜狗输入法，安装过程保留了这一选择；切回「方寸输入法」即可使用新版本。

## 实现依据与限制

候选由 Rime 自己维护高亮和分页；开启横向候选导航后，在全局首项向左或光标位于拼音中时，交给不循环的逐字导航。依据 [Rime 1.17.0 Selector 实现](https://github.com/rime/librime/blob/1.17.0/src/rime/gear/selector.cc)。上下键独立使用候选高亮接口，保留原有操作，并拦截候选边界按键。

以上控制器测试直接向实际控制器发送事件并检查真实 NSTextView；它不经过 macOS 系统键盘路由，不能代替浏览器、聊天软件等真实应用的手动验收。本机缺少系统自动按键权限，本次不将这一层标为通过。

本次只修正候选导航。build 11 已记录的失焦丢尾部、部分选词后 Enter 还原拼音、待译草稿编辑等问题仍保留为失败项，见 [完整输入审计](../input-behavior-and-usability.md)。没有更改历史测试报告。
