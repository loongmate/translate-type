# build 22：原生 AI 动作与问答

对应原型：`design/ai-actions.html`。本次实现使用 AppKit、现有 Rime 会话和 OpenAI-compatible Chat Completions；不依赖 HTML 页面。

## 入口和使用

- 方寸处于当前输入源时，在原输入框按 **Ctrl + Shift + Enter**。第一个页签是「改文字」，初始动作「翻译成英语」，之后记住所选动作。
- 候选窗的对话图标、系统输入法菜单「问 AI…」可直接进入问答。已确认的草稿可以作为问题带入；仍有拼音候选时须先完成选词。
- 「改文字」提供英语、德语、提取约定、说得自然点。点击「＋ 自定义」，填写名称、可选 key 和特殊指令。菜单上方可按名称或 `/key` 搜索。修改预设另存副本；自定义动作可修改、删除。
- 「问 AI」输入问题或写作任务，可附参考文字。拿到回答后可修改、继续追问，也可选择此前回答版本再追问。
- 原文、参考文字、追问均支持全拼/双拼、中文和英文混输。结果区默认英文直输，轻按 Shift 后也可输入中文；各字段支持独立编辑和撤销。

## 快捷键和上屏

| 操作 | 结果 |
| --- | --- |
| 空格 | 确认拼音候选，不调用模型 |
| Enter | 编辑区换行；还有拼音时先原样输入字母 |
| Ctrl + Enter | 执行当前动作；光标在追问框时发送追问 |
| Cmd + Enter | 结果上屏；结果有选区时仅插入选中部分 |
| Cmd + Shift + Enter | 改文字模式下原文上屏；问答模式不会把问题当结果上屏 |
| Cmd + C /「复制选中」 | 复制选中结果 |
| Esc | 先取消当前未确认拼音；无待选输入时保留并收起 |
| Cmd + W / 关闭 | 保留并收起，不上屏 |

改文字还没有生成过结果时，Cmd + Enter 可沿用旧版习惯直接插入原文。生成后若修改了原文或动作，旧结果只供查看，需重新执行，或明确选择「原文上屏」。请求进行中不得插入未完成的结果。

上屏仍使用 build 21 的异步焦点交接：先关闭面板、还给宿主焦点，再校验目标并写入一次。不发送消息、不模拟按键、不通过剪贴板偷偷粘贴。目标确实变化时保留草稿，允许明确重新绑定。

成功上屏后新打开的编辑区仍可输入新内容；点击「上次内容」可取回刚才的两种模式草稿、参考文字、回答版本和已编辑结果，再选取另一段或追问。当前有未处理草稿时不会直接覆盖。收起则直接恢复本次编辑。草稿和回答只保存在当前进程内，退出输入法后不保留。

## 请求规则与边界

- 保存配置、打字、空格选词、切换动作、修改结果均不请求模型。
- 英语动作使用已有翻译偏好；其他动作替换系统指令，避免混入“必须翻译成英语”的规则。
- 问题、参考资料、动作指令、历史回答分别组装为消息；追问以当前选定且修改后的回答为上下文。
- 切换模式、改原文或资料会取消旧请求，过期响应不能覆盖当前内容。
- 请求失败或停止不自动重试；输入和可用的上次回答保留。最近保留 20 个回答版本；单次输入、参考资料和追问分别最多 20,000 字，会话合计超过 60,000 字时提示精简。
- 复用现有模型连接和钥匙串；DeepSeek 官方接口继续明确关闭思考。通用兼容服务不附加不支持的专属字段。
- 本轮“做事”是生成、整理和处理文字。没有接入联网、文件操作或自动执行工具。

## 验证方式

`FANGCUN_EDITOR_TEST=AIActionTests ./scripts/editor-test.sh` 使用真实 Rime、原生面板、带 NSTextView 的 IMK 测试客户端和本机模拟的 OpenAI-compatible 服务。检查请求体、模式草稿、追问分支、取消、失效、中文选词、局部上屏、撤销与复制；不会发送用户内容或使用用户密钥。

既有 `editor-test.sh`、`controller-test.sh`、`test.sh` 验证普通输入和 build 21 的交接回归。原生截图由测试窗口自身渲染，保存在 `.build/build22-ai-ask.png` 和 `.build/build22-ai-transform.png`。

本机模拟服务证明请求与交互链路正确，不代表第三方模型输出质量。真实 ChatGPT 等应用中的跨进程交接继续使用此前用户已验证的路径；本轮新增的不同宿主组合仍需实际日常使用检验。

安装验证：build 22 已安装到 `~/Library/Input Methods/FangCun.app`；签名验证通过，安装后的可执行文件 SHA-256 与构建产物一致。系统报告输入源已启用、可选择。安装保留了用户当前选择的 ABC，没有强制切换输入源。

真实服务探针使用固定的德语翻译和中文活动建议两条样例，不读取用户草稿。第一次验证停在 `SecItemCopyMatching` 获取现有密钥的系统调用中，没有得到服务结果；未将此项标记为通过。探针进程已停止，等待用户处理 macOS 钥匙串授权。模型连接本身已通过本机兼容服务的请求、取消与错误检查。
