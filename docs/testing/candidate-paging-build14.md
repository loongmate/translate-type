# 候选翻页验收 · build 14

日期：2026-10-11。环境：macOS 14.7.4 / Intel，Rime 1.17.0。

## 修复与操作

此前控制器只将 Page Up / Page Down 作为翻页键，`-`、`=`、`+` 进入普通标点处理，因此不能用常见的加减号按键翻页。

现在有未确认的拼音候选时，`-` 上一页，`=` 或 `+` 下一页。支持主键盘、Shift＋等号产生的加号和数字键盘加减号。全拼和七种双拼，以及中文直接上屏、译英暂存两种输出模式均适用。

- 首页／末页停住，不绕回、不插入符号、不确认候选。
- 翻页保留原拼音、编辑光标和已经选好的中文；空格确认当前高亮项，数字选择当前页对应项。
- 无候选、已选完的中文草稿和英文直输时，符号正常输入。
- Command / Control / Option 组合仍交给宿主应用，例如 Command＋加号的放大操作。
- 原有左右键选词、拼音内部编辑、Page Up / Page Down 和翻页按钮继续使用；未完成选词仍禁止 Ctrl＋Enter 翻译。

设置页及候选窗翻页箭头增加了对应快捷键提示。

## 本机体验检查

1. 选中方寸，输入 `ni`：按 `=` 或 `+` 应换一组候选，按 `-` 返回；空格与数字键选中当前页的词。
2. 首页按 `-`、末页反复按 `+`：输入框不多出符号，也不提前上屏。
3. 开启译英，先选词形成中文草稿，再输入 `ni` 翻页：草稿应保留，未选完时 Ctrl＋Enter 不翻译。
4. 轻按 Shift 切英文，输入 `a-b+c=1`：应完整输出原字符。

build 11 已记录的失焦丢尾部、部分选词后 Enter 还原编码等缺陷不属于本次翻页修复，仍见 [完整输入审计](../input-behavior-and-usability.md)。
