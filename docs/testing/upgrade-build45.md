# build 45：覆盖升级与旧宿主输入会话

日期：2026-11-05。环境：Intel / macOS 14.7.4。

## 问题与范围

用户反馈安装 build 44 后出现两个紫色“中”状态图标。强制退出并另起实例后，原来已打开的应用无法继续输入，重启恢复。安装器只检查目标目录的旧进程、把文件替换和新进程启动等同于升级完成，遗漏了旧宿主仍持有旧输入会话的场景。新进程和磁盘版本不能证明 IMK 客户端已经重新连接。

本版不尝试声称热迁移成功：覆盖升级、发现旧产品进程、此前选中本产品输入源三种情况均返回需要重新登录，不启动新实例或自动切回方寸。界面在安装前提示保存未提交文字，安装后要求保存所有工作、退出登录后重新登录；不会自动注销。首次安装且没有旧会话时保留正常启动流程。

进程检查按当前及历史产品标识覆盖各路径，排除安装器和其他产品。等待退出时重新枚举，处理重新出现的进程；首次启动需核对唯一 PID 和应用、可执行文件路径，拒绝旧 PID、错误路径与多实例。没有使用强制创建新应用实例的配置。

## 验证

- `FANGCUN_ARCHS='x86_64 arm64' ./scripts/build.sh`：双架构构建通过。
- `./scripts/installer-test.sh`：51 项检查通过。实际原生安装按钮覆盖升级后显示需要重新登录，禁用开始使用，不调用启动或切回输入源。另覆盖旧副本退出、重新出现、强制退出、拒绝退出、缺少部分元数据、首次安装、注册传播延迟及失败回滚。
- 文件复制、备份和回滚在临时目录真实执行；系统注册、进程和启动行为使用替身。测试未终止或覆盖本机当前输入法。
- 已检查原生安装前界面和覆盖升级完成界面的截图，保存工作、重新登录提示及禁用按钮完整可见。
- 输入核心及方案资源未修改，沿用 build 44 已通过的标点 2,304 用例 / 11,699 断言、核心 913、双拼 179、控制器 116、临时编辑区 149、生命周期 13 项记录。
- 在隔离 Rime 用户目录先加载旧方案再加载新方案，八套方案均升级缓存并输出 `你好，` 和中文左双引号；未删除真实用户词库或配置。

## 最终包检查

两种架构最终 DMG 均通过签名、Apple 公证票据、Gatekeeper、磁盘映像完整性检查。输入法、安装器和 Rime 库均为对应的单一架构；版本为 build 45，最低系统声明为 macOS 13。包内资源与构建产物一致，安装说明包含覆盖升级需要重新登录。

对 DMG 内真实 payload 执行生产 InstallTransaction 的复制和重命名后，签名、公证票据及 Gatekeeper 仍有效；未安装到本机生产输入法目录。远端附件发布时核对名称、大小、摘要及下载可达性。
