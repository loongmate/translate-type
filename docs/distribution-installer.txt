安装与升级

1. 先保存工作并确认尚未提交的文字。
2. 打开 DMG，双击“安装方寸输入法”，点击安装，无需管理员密码。
3. 等待安装完成，再从系统输入菜单选择方寸。若首次安装提示“需要重新登录”，
   请保存工作并退出登录，重新登录后再选择方寸。
4. 升级后回到原来已打开的窗口确认能继续输入。若原窗口无法输入，请保存工作，
   退出登录后重新登录，再从系统输入菜单选择方寸。
5. 可以推出 DMG。设置从方寸状态图标或输入法菜单打开。

通常安装在 ~/Library/Input Methods/FangCun.app；已有旧安装名时沿用原路径，
避免注册路径在升级期间消失。备份位于：
~/Library/Application Support/FangCun/Installer/Backups/
不会清除模型配置、API Key、词库或临时编辑器恢复稿。

新版启动、就绪检查或输入源恢复失败时尝试原子回滚旧版。
旧进程拒绝正常退出则中止升级，不强行结束它。
首次安装若 macOS 尚未识别输入源，仍可能提示重新登录；该结果不视为立即可用。
系统级安装或多个安装目录副本会使安装器停止，避免产生重复安装。

系统要求：macOS 13+，按芯片选择 Apple Silicon（M 系列）或 Intel 版。

离线中文输入无需 API Key；打字和选词不会请求模型。
只有主动执行 AI 时，相关文字及必要的对话或工具结果才发送至所配置服务。
“问 AI”的文件和 Shell 工具具有当前用户权限，工作目录不是权限沙箱。
API Key 位于本机权限为 0600 的私有文件中，未额外加密。

源代码、校验文件和问题反馈：https://github.com/loongmate/translate-type
依赖许可证保存在输入法应用 Contents/Resources 内。
