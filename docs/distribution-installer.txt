方寸输入法 · 自动安装版

安装：
1. 打开 DMG，双击“安装方寸输入法”。
2. 点击“安装方寸输入法”，等待结果。无需管理员密码。
3. 显示安装完成后，点击“开始使用”，或从系统输入菜单选择“方寸输入法”。
4. 可以推出 DMG。安装器会自动打开方寸设置，AI 功能需自行配置模型服务。

安装器自动将输入法复制到当前用户的 ~/Library/Input Methods/FangCun.app，
注册、启用系统输入源并检查是否可选。不要将安装器或内置输入法拖进“应用程序”。
若 macOS 暂未识别新的输入法，会明确显示“需要重新登录”：请先保存工作，
退出登录后重新登录，再到系统设置 → 键盘 → 文本输入 → 编辑 → ＋ → 简体中文添加。
首次安装可能仍需手动添加；程序不会自动退出登录或重启。

升级前请保存未提交的文字。安装器只退出本产品的旧进程，备份旧应用后替换；
注册或启动失败时尝试恢复旧版。备份存放在：
~/Library/Application Support/FangCun/Installer/Backups/
不会清除现有模型配置、API Key、用户词库或临时编辑器恢复稿。
若检测到 /Library/Input Methods/ 下已有方寸，安装器会停止，避免重复安装。

系统要求：macOS 13+，按芯片选择 Apple Silicon（M 系列）或 Intel 版。
当前实测环境为 Intel / macOS 14.7.4，Apple Silicon 和 macOS 13 尚待真机验证。
签名与公证状态见本文开头及下载页面。

离线中文输入无需 API Key；打字和选词不会请求模型。
只有主动执行 AI 动作时，相关文字与必要的对话或工具结果才发送至所配置的服务。
“问 AI”的文件和 Shell 工具具有当前用户权限，工作目录不是权限沙箱。
API Key 保存在本机权限为 0600 的私有文件中，不使用钥匙串，未额外加密。

卸载：切换到 ABC，在系统键盘设置移除方寸，退出方寸后移走已安装应用。
卸载应用不会主动删除用户数据、凭据、恢复稿或旧版快照。

源代码、校验文件和问题反馈：https://github.com/loongmate/translate-type
依赖许可证保存在输入法应用的 Contents/Resources 内。
