方寸输入法 · 0.1.0-beta.1 预览版（build 22）

本包只有临时代码签名，没有 Developer ID 签名或 Apple 公证。
首次打开可能被 macOS 拦截，需要由你在系统设置中确认允许此应用。
安装器与正式签名将在后续版本提供，本版需要手动安装。

构建目标为 macOS 13 或更高版本，Apple Silicon 版与 Intel 版分别下载。
本包对应的芯片见本文第一行，应用和 Rime 引擎均只包含这一种架构。
在苹果菜单 → 关于本机中查看：“芯片”显示 Apple M 系列，选 Apple Silicon 版；
“处理器”显示 Intel，选 Intel 版。
目前实测环境为 Intel / macOS 14.7.4；Apple Silicon 和 macOS 13 尚待实机验证。

首次安装：
1. Finder 按 Cmd + Shift + G，前往 ~/Library/Input Methods/。
   如果目录不存在，可在 ~/Library/ 中创建 Input Methods 文件夹。
2. 将 FangCun.app 复制到该文件夹，不要在解压目录直接启动输入法。
3. 双击复制后的 FangCun.app。若提示无法验证开发者或无法检查恶意软件，
   打开系统设置 → 隐私与安全性，在安全性区域点击“仍要打开”，再确认“打开”。
   较旧系统的入口名称可能是“安全性与隐私”。只对你确认来源的方寸应用执行此操作。
   这是针对该应用的例外，不需要全局关闭 Gatekeeper 或 SIP。
4. 应用打开后，在设置中点击“添加到系统输入法”。
5. 从系统输入菜单选择“方寸输入法”。
   若没有出现，在系统设置 → 键盘 → 文本输入 → 编辑 → ＋ → 简体中文中添加。
   新装输入法在部分系统会话中需要重新登录后才能被识别。

Apple 的操作说明：https://support.apple.com/zh-cn/102445
受管理的 Mac 可能禁止“仍要打开”。若提示应用已损坏或将损坏电脑，请停止安装，
核对下载文件的 SHA-256 并反馈具体提示，不要通过关闭系统保护来跳过。

已有开发版的机器请继续使用仓库 scripts/install.sh 更新，避免替换正在运行的输入法。
不要同时在 ~/Library/Input Methods/ 和 /Library/Input Methods/ 安装两个副本。

离线中文输入不需要 API Key。AI 功能需要在设置 → AI 中填写自己的兼容接口、模型和 API Key。
打字不会自动请求模型；只有主动执行翻译、动作或提问时才发送对应内容。
Ctrl + Shift + Enter：临时编辑区；Ctrl + Enter：执行；Cmd + Enter：上屏。

卸载：先切换到 ABC，在系统键盘设置中移除方寸，退出方寸后移走安装的 FangCun.app。
卸载应用不会主动删除词库、偏好或钥匙串密钥。

源代码与发布准备说明：https://github.com/loongmate/translate-type
引擎、词库及方案的许可保存在 FangCun.app/Contents/Resources/ 内。
