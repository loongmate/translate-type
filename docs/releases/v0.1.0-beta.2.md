## 安装与升级

**本版采用 ad hoc 临时代码签名，没有 Developer ID 签名和 Apple 公证，需手动安装。**

1. 下载适合芯片的 DMG，双击打开。
2. 在 Finder 按 **Cmd + Shift + G**，前往 `~/Library/Input Methods/`；目录不存在时，在 `~/Library/` 下新建 `Input Methods` 文件夹。
3. 将 DMG 内的 `FangCun.app` 复制到该目录，然后推出 DMG。不要复制到「应用程序」，也不要从 DMG 内直接启动。
4. 双击安装后的应用。若 macOS 提示无法验证开发者或无法检查恶意软件，关闭提示，前往 **系统设置 → 隐私与安全性 → 安全性 → 仍要打开**，按提示确认。
5. 在方寸设置中点击 **添加到系统输入法**，随后在系统输入菜单选择 **方寸输入法**。
6. 若暂未出现，在系统设置 → 键盘 → 文本输入 → 编辑 → ＋ → 简体中文中添加；部分系统会话需要退出登录后重新登录。

升级前保存未提交的 AI 草稿，切换至 ABC，在「活动监视器」中退出方寸的 `TranslateType` 进程，再替换原安装路径中的应用。重新打开后若仍使用旧版本，请退出登录再登录。源码开发用户也可继续使用 `scripts/install.sh`，它会处理备份与进程切换。保留原用户词库、偏好和本机凭据；不要在用户目录和 `/Library/Input Methods/` 同时安装副本。本版没有自动更新。

## 相比 beta.1 的更新

- 新增独立临时编辑器：中文输入、撤销重做、查找替换、UTF-8 文件打开与另存、本机恢复稿；支持 Markdown、静态 HTML、JSON 与纯文本预览。
- 「问问 AI」升级为多轮消息流 agent，可按用户请求读写文件、执行本机命令及读取和搜索网页；支持停止、新建对话和恢复上次内容。
- 候选窗支持选择及自定义 AI 动作，包括译英、英语润色、问答；未完成选词时禁止执行，避免误处理拼音。
- 新增离线 emoji 和符号候选，全拼、七种双拼及临时编辑区共用。
- 增加独立「中／英」语言状态图标与「问问 AI」「临时编辑器」菜单入口，系统保留单一方寸输入源。
- 改进网址、邮箱、路径与代码片段输入及标点处理；保留 Shift 中英文切换和候选翻页。
- API Key 改为按服务地址保存在本机私有文件，避免钥匙串授权阻塞输入法。

## AI 与本机数据

在设置 → AI 中填写基础地址、模型和自己的 API Key。打字和选词不会调用模型，只有主动执行 AI 时才发送相关文字和必要的对话、工具结果至所配置的服务。

API Key 位于 `~/Library/Application Support/TranslateType/Credentials/api-keys.json`，文件权限 0600、目录 0700，未额外加密，不使用钥匙串。旧版本仅保存在钥匙串的 Key 需重新填写。

「问 AI」的文件与 Shell 工具使用当前用户权限，所选工作目录是路径基准，不是权限沙箱。停止操作会取消请求和当前命令，已经写入的文件不会自动回滚。临时编辑器恢复稿存于 `~/Library/Application Support/FangCun/Scratchpad/draft.json`；预览不会运行内容脚本或自动加载远程资源。AI 对话与原临时编辑区草稿仍主要保存在当前进程内。
