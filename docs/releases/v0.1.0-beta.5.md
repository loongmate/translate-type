## 安装与升级

1. 保存所有工作，尤其是尚未确认上屏的文字，再打开适合芯片的 DMG，双击 **安装方寸输入法**。
2. 点击 **安装方寸输入法**，等待安装结果。安装后的输入法位于当前用户的 `~/Library/Input Methods/FangCun.app`。
3. **覆盖升级会显示「需要重新登录」**。从苹果菜单退出登录后重新登录，再选择方寸；重新启动 Mac 也可以。只关闭安装器、锁屏或切换输入法无法保证旧应用的输入会话更新。安装器不会自动注销或重启。
4. 首次安装且没有发现旧进程或旧输入会话时，完成后可点击 **开始使用**。如果系统尚未识别输入源，也会提示重新登录。
5. 推出 DMG。不要把安装器拖进「应用程序」。需要设置时，从方寸状态图标或输入法菜单主动打开。

升级检查本产品在各路径运行的进程，等待其退出后再替换应用，不强制创建新实例来冒充会话迁移成功。旧应用备份到 `~/Library/Application Support/FangCun/Installer/Backups/`；注册、启用等失败时尝试恢复旧版。保留既有模型配置、API Key、词库和临时编辑器恢复稿。若已有系统级安装或多个安装目录副本，会停止并提示处理。

## 本次修复

- 修正覆盖升级报告“可开始使用”的判断。即使新版文件已复制、系统可选输入源已启用，也需重新登录来重建已打开应用的输入会话。
- 扩大旧进程检查范围，包含从下载目录、DMG 等其他位置运行的本产品副本；等待退出并检查重新出现的进程，避免遗漏旧实例。
- 首次安装的启动检查会核对进程数量、PID、应用路径与可执行文件路径，发现重复或错误副本时明确报错。
- 保留 build 44 的中文标点和设置弹窗修复：全拼、七种双拼输入待选文字后按中文标点会确认候选；切换应用或输入法不会自动打开设置。

## 验证与已知边界

51 项安装器检查通过，包含覆盖升级的实际安装按钮、重新登录提示、重复进程、其他路径副本、进程重新出现、退出失败、首次安装和失败回滚。文件复制、备份和回滚实际在临时目录执行；系统注册和进程场景使用替身。两种架构最终安装包完成内容、完整性及签名、公证检查。

测试环境为 Intel / macOS 14.7.4。未证明已打开的各类宿主应用可以无缝迁移输入会话，本版采用重新登录的升级流程；没有在全新用户账户完成完整首次安装。Apple Silicon 已交叉编译和检查安装包，尚待真机运行；macOS 13 尚待实机验证。输入核心与 build 44 相同，沿用其 2,304 个标点用例及核心、双拼、控制器、临时编辑区和生命周期回归记录。

## 数据与卸载

离线输入不需要 API Key，打字和选词不会请求模型。AI 功能使用你配置的兼容服务；只有主动执行 AI 时才发送相关文字及必要的对话或工具结果。「问 AI」的文件和 Shell 工具使用当前用户权限，工作目录不是权限沙箱。

API Key 位于 `~/Library/Application Support/TranslateType/Credentials/api-keys.json`，目录权限 0700、文件权限 0600，未额外加密。临时编辑器恢复稿位于 `~/Library/Application Support/FangCun/Scratchpad/draft.json`。

卸载时先切换到 ABC，在系统键盘设置移除方寸，退出方寸后移走已安装的应用。配置、词库、凭据、恢复稿和旧版快照不会自动删除。

引擎、词库与预览库许可证保留在输入法应用资源内，对应源码、方案和安装器实现包含在本版本标签中。问题反馈请使用 [Issues](https://github.com/loongmate/translate-type/issues)，附芯片、macOS 版本和复现步骤，不要附 API Key。
