## 安装与首次打开

**本版没有 Developer ID 签名和 Apple 公证，采用手动安装。** 有临时代码签名用于保持应用完整性，但这不等于 Apple 的开发者身份认证或公证。

1. 下载适合芯片的 ZIP 并解压。
2. 在 Finder 按 **Cmd + Shift + G**，前往 `~/Library/Input Methods/`。如果目录不存在，在 `~/Library/` 下创建 `Input Methods` 文件夹。
3. 将 `FangCun.app` 复制到该目录，再双击复制后的应用。
4. 若系统提示无法验证开发者或 Apple 无法检查恶意软件，先关闭提示，再前往 **系统设置 → 隐私与安全性 → 安全性 → 仍要打开**，按提示再次确认打开。较旧系统可能称为“安全性与隐私”。这是针对该应用的例外，无需关闭系统整体保护。[Apple 操作说明](https://support.apple.com/zh-cn/102445)
5. 在方寸设置中点击 **添加到系统输入法**，随后在菜单栏选择 **方寸输入法**。
6. 若暂未出现，到系统设置 → 键盘 → 文本输入 → 编辑 → ＋ → 简体中文中添加；部分系统会话需要退出登录后重新登录。

受管理的 Mac 可能禁止“仍要打开”。若提示应用已损坏或将损坏电脑，请停止安装，核对下载摘要并反馈具体提示。不要同时在用户目录和 `/Library/Input Methods/` 安装两个副本。已有开发版请使用源码中的 `scripts/install.sh` 更新，它会处理进程切换和备份。

## 本版功能

- 全拼、七种双拼、中英混输、候选翻页与 Shift 中英文切换。
- 中文直接上屏，或开启译英后暂存整段，主动执行一次翻译。
- 原生临时编辑区：粘贴、编辑、撤销、长文滚动，以及直接写回原输入框。
- **改文字**：默认译英，提供德语、提取、改写和自定义动作。
- **问 AI**：提供参考文字、追问、回答版本，以及选择部分结果复制或上屏。

在设置 → AI 中填写服务地址、模型和自己的 API Key。密钥保存在本机钥匙串；执行 AI 动作时，相关文字、指令及必要的对话内容会发送至你配置的模型服务。打字和选词不会自动调用模型。

## 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| Ctrl + Shift + Enter | 打开临时编辑区（方寸为当前输入源时） |
| Ctrl + Enter | 主动翻译、转换或提问；先完成候选选词 |
| Cmd + Enter | 编辑区结果上屏，有选区时只上屏选中部分；改文字尚未生成结果时可上屏原文 |
| Cmd + Shift + Enter | 改文字模式原文上屏 |

## 验证与已知限制

- 构建目标为 macOS 13+；目前实测为 Intel / macOS 14.7.4。Apple Silicon 构建、架构与签名完整性检查通过，**尚待真机验收**。
- 既有功能自动检查 489 项通过；模型部分主要使用模拟服务。不同模型及不同宿主输入框的兼容性仍需继续收集反馈。
- 本版没有一键安装器和自动更新。编辑区草稿主要保存在当前进程内，更新、退出或重启前请保存需要保留的内容。
- 部分复杂输入行为仍有历史待复核项，详见仓库内的输入行为与测试文档。

词库和依赖许可证随应用资源保留，对应可编辑词库和生成脚本包含在本标签源码中。下载、安装或输入过程中遇到问题，可在 [Issues](https://github.com/loongmate/translate-type/issues) 提供芯片型号、macOS 版本与复现步骤；请勿附上 API Key。
