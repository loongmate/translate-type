## 安装与升级

1. 打开适合芯片的 DMG，双击 **安装方寸输入法**。
2. 点击 **安装方寸输入法**。升级前请先保存尚未提交的文字。
3. 等待安装结果。完成后点击 **开始使用**，或从系统输入菜单选择 **方寸输入法**。安装器会打开方寸设置，可以配置 AI 或选择拼音方案。
4. 推出 DMG。安装后的输入法位于当前用户的 `~/Library/Input Methods/FangCun.app`，无需将安装器拖进「应用程序」。

安装器检查应用完整性，复制文件、注册并尝试启用输入源，再检查其是否可选。部分 macOS 会话可能暂未发现新输入法：此时会明确显示 **需要重新登录**，保留已安装应用。请保存工作，退出登录后重新登录；若还未出现，打开方寸设置点击「添加到系统输入法」，或在系统设置 → 键盘 → 文本输入 → 编辑 → ＋ → 简体中文中添加。安装器不会自动注销或重启。

升级时只退出本产品旧进程，将旧应用备份到 `~/Library/Application Support/FangCun/Installer/Backups/` 后再替换；注册、启用或启动失败会尝试恢复旧版。不会修改既有模型配置、API Key、词库和临时编辑器恢复稿。若已有系统级安装（`/Library/Input Methods/`）或多个本产品副本，安装器会停止并提示处理，避免重复安装。

## 本次修复

- 中文模式下，拼音后直接按逗号、句号、问号等标点，会确认当前高亮候选并输入中文标点。例如 `nihao,` → `你好，`，无需先按空格，拼音不会被整体退回字母。
- 补齐中文方括号 `【】`、书名号 `《》` 和成对双引号 `“”`；全拼、七种双拼、译英草稿与临时编辑区行为一致。
- 修复部分双拼方案不使用分号编码，却把分号吞进拼音的问题；搜狗、微软、紫光的分号编码仍保留。
- 切换输入法、切换应用和后台服务重新打开时不再自动弹出设置窗口。设置可从输入法菜单、候选窗齿轮或紫色状态图标菜单主动打开；安装完成后仍可正常打开设置。
- 输入网址、路径和代码时，可用 Shift 切到英文模式保留半角标点。中文模式下，`@`、`_` 等开启的原文片段仍保持原样。

## 数据与卸载

离线输入不需要 API Key，打字和选词不会请求模型。AI 功能使用你配置的兼容服务；只有主动执行 AI 时才发送相关文字及必要的对话或工具结果。「问 AI」的文件和 Shell 工具使用当前用户权限，工作目录不是权限沙箱。

API Key 位于 `~/Library/Application Support/TranslateType/Credentials/api-keys.json`，目录权限 0700、文件权限 0600，未额外加密。临时编辑器恢复稿位于 `~/Library/Application Support/FangCun/Scratchpad/draft.json`。

卸载时先切换到 ABC，在系统键盘设置移除方寸，退出方寸后移走已安装的应用。配置、词库、凭据、恢复稿和旧版快照不会自动删除。

引擎、词库与预览库许可证保留在输入法应用资源内，对应源码、方案和安装器实现包含在本版本标签中。问题反馈请使用 [Issues](https://github.com/loongmate/translate-type/issues)，附芯片、macOS 版本和复现步骤，不要附 API Key。
