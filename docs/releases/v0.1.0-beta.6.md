# 方寸输入法 0.1.0-beta.6 · build 47

- **临时编辑器**增加行号、语法着色和深色预览，保留查找替换、文件打开、另存和草稿恢复。
- **问问 AI**增加会话侧栏和可折叠的工具记录。切换会话时恢复本次使用中的消息、草稿、参考文字和工作目录。
- **中文输入**支持直接输入 `baidu.com`、`www.baidu.com` 等网址。未选拼音后的句号会暂留在预编辑区，选词后的句号立即上屏。
- **安装器**升级时沿用已有安装路径，备份旧版，并在启动新版后检查输入服务是否就绪。启动或输入源恢复失败时会尝试回滚。

## 下载与安装

| Mac 芯片 | 安装包 |
| --- | --- |
| Apple Silicon（M 系列） | [下载 DMG](https://github.com/loongmate/translate-type/releases/download/v0.1.0-beta.6/FangCun-0.1.0-build47-AppleSilicon-installer.dmg) |
| Intel | [下载 DMG](https://github.com/loongmate/translate-type/releases/download/v0.1.0-beta.6/FangCun-0.1.0-build47-Intel-installer.dmg) |

系统要求为 macOS 13 或更新版本。下载页同时提供两份 `.dmg.sha256` 校验文件。

保存工作后打开对应 DMG，双击「安装方寸输入法」。安装器将方寸安装到当前用户的 `~/Library/Input Methods/`，无需管理员密码。升级会保留配置、词库和草稿。

首次安装若提示「需要重新登录」，请退出登录并重新登录。升级后请在原应用窗口确认能继续输入。如果输入没有恢复，请保存工作后重新登录，再从系统输入菜单选择方寸。

## 验证范围

已在 Apple Silicon 上验证新版工作窗口，并通过全拼、双拼、中文标点和安装器回归检查。两种架构分别构建。仍需在 Intel 上验证本版安装后的实际使用，并在已连接旧版方寸的应用窗口验证升级后的输入恢复。
