## 放大编辑交互原型

打开 [expanded-editor.html](expanded-editor.html)（本机预览：<http://127.0.0.1:8765/design/expanded-editor.html>）。这是可操作的 HTML 原型，与下方的静态组件稿分开保存。

从小候选窗右上角「放大编辑」进入独立临时编辑区。候选窗和编辑区共用同一份草稿，原应用的输入框只是最终的上屏目标。

| 操作 | 交互规则 |
| --- | --- |
| 放大 / 缩小 | 保留完整原文、选区和滚动位置；窗口可拖动、拖拽调整大小，也可切换大窗口。 |
| 输入 / 粘贴 | 普通多行编辑器；Enter 换行；可选中、复制、粘贴，粘贴替换选中部分或插入光标处。浏览器不允许按钮读取剪贴板时提示使用系统粘贴快捷键。 |
| 暂时收起 | 保留草稿，通过「继续编辑」返回；收起不自动上屏。 |
| 清空 | 清空编辑区，短暂提供「撤销」；不修改原输入框。 |
| 翻译 | 完成选词后点击「翻译整段」或 Ctrl + Enter，只请求一次。输入、空格、换行、修改风格都不自动请求。 |
| 请求中 / 失败 | 支持停止；失败保留原文，主动重试。继续修改原文会使进行中的结果失效。 |
| 译文就绪 | 宽窗口左右对照，窄窗口用原文 / 译文标签切换。译文可改、可复制；原文或风格变化后需要主动重新翻译。 |
| 上屏 | Cmd + Enter：有译文时上屏译文，否则上屏原文；Cmd + Shift + Enter 始终上屏原文。一次写回原输入位置，随后收起，不用复制粘贴、不发送消息。按钮标明快捷键；原型提供短暂撤销。翻译中 Cmd + Enter 不提交中文，未选完时禁止上屏。 |
| 切换输入框 | 草稿保留，禁止向另一个输入框误上屏；回到原输入框后继续。原输入框内容变化时需要重新确认插入位置。 |

原型底部提供长文、空白输入、切换输入框三个体验入口；右上角「交互说明」可模拟下一次翻译失败并查看请求次数。可直接打开 `#expanded` 查看编辑区。

### 原生实现时的状态约定

- 临时编辑区属于输入法浮窗，不绑定原输入框的可视尺寸。浮窗获得编辑焦点后，原上屏目标需要独立保存。
- 草稿、正在合成的拼音 / 候选、译文是不同状态。放大不应自动选词或把拼音变成正文；输入引擎应保留当前合成状态，在编辑区内继续完成选词。未完成选词仍禁止翻译。
- 编辑区内部的空格选词、数字选词、双拼和中英混输应继续由现有输入引擎处理；不在 HTML 或编辑器层重复造选词逻辑。
- 目标应用退出、光标或选区失效时保留草稿，并提供复制 / 重新选择上屏位置，禁止静默写入其他应用。
- 本原型用浏览器 `compositionstart` / `compositionend` 防止选词期间触发翻译；真实 Rime 合成状态迁移及跨应用焦点处理还需要原生实现和测试。

### 原型边界

HTML 不连接模型、系统输入法或真实应用。默认短文和长文有固定演示译文；自行输入的内容返回明确标注的交互占位示例，风格选项只演示失效与重新请求的流程。草稿仅存在本页内存中，刷新会重置。设计原型阶段没有更改或重新安装原生输入法；后续原生实现单独记录。

浏览器验收记录和截图见 [design-qa.md](design-qa.md)。

## 静态组件稿

打开 `index.html` 查看静态组件设计稿。CSS 内嵌在 HTML 中，图标使用随文件保存的 Lucide。

本次以桌面中文输入法候选窗为产品主体，不提供后台、个人工作空间或独立工作台。

1. **默认状态**：拼音串、横向中文候选、数字选词和空格上屏。右上角增加一个默认关闭的「译英」开关。
2. **译英输入中**：空格照常确认中文候选，但中文累计在预编辑区，不立即上屏、不调用模型。还有未确认的输入时，Ctrl + Enter 不执行翻译，按钮显示「先完成选词」并禁用，输入保持原样。选词全部完成后，点「翻译整句」或按 Ctrl + Enter，对整个暂存句子发起一次翻译请求。
3. **翻译完成**：默认展示一条英文译文和中文原文。Enter 确认英文上屏，不产生新请求；Esc 回到中文预编辑区。请求期间保留中文并提示等待，失败后可直接选中文上屏。
4. **齿轮小窗**：按需打开模型配置，服务地址、API Key、模型名称与选填的「特殊指令」集中在小浮窗内。

## 特殊指令

「特殊指令」作为独立配置字段定制翻译 prompt，与 API Key 分开。空字符串或仅空白时使用默认规则：忠实保留原意，译成自然英文，保留人名和术语，只返回一条译文，不附解释。

预设设计：选择后将指令填入输入框，允许继续编辑；选择「默认」清空输入框。

- **自然口语**：用自然的日常英语表达，语气轻松，避免书面腔，保留原意、人名和术语，只返回译文。
- **商务礼貌**：用专业、礼貌的商务英语表达，保持简明，不添加原文没有的承诺或信息，只返回译文。
- **简洁直译**：尽量贴近原文，使用简洁英文，不扩写、不润色增义，只返回译文。

修改指令或选择预设不调用模型，也不自动重译。指令随下一次主动发起的整句翻译请求发送。

当前设计稿只展示输入框和预设外观，预设选择、保存和 prompt 拼接行为留待正式实现。

## 调用原则

- 逐字输入、拼音变化、选词、停顿、空格和标点不触发模型请求。
- 默认一次整句请求只产生一条英文译文，不自动生成多版本。
- 请求尚未完成时禁用重复翻译触发；修改中文后旧译文失效，但不会自动重新请求。
- 翻译失败不后台重试；用户主动重试才产生新请求。
- 翻译触发快捷键暂定 Ctrl + Enter，后续可配置。

配色为轻紫色高亮和白色候选面板。候选窗跟随实际输入光标。页面上的标签和说明只用于审阅设计稿，不属于正式输入法界面。

该文件仅为静态设计稿，没有交互、拼音引擎、系统输入法接口或模型请求。句子、译文和密钥掩码均为设计样例。
